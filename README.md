# Northstar Medical Group Website

A professional, modern, and responsive medical services website.

## 🚀 Deployment Guide

### 1. Hosting on Netlify (Free & Global)
1. Sign up at [netlify.com](https://www.netlify.com/) using your GitHub account.
2. Click **Add new site** $\rightarrow$ **Import an existing project**.
3. Connect to GitHub and select the `medical-company-portfolio-website` repository.
4. Click **Deploy**. Your site will be live on a global CDN with a free `.netlify.app` domain.

### 2. Custom Domain & Email (Zero Cost)
- **Domain**: Netlify provides a free subdomain. For a professional feel, use the provided `your-site.netlify.app`.
- **Email**: Use **Zoho Mail's Forever Free Plan** to create a professional inbox (e.g., `info@yourdomain.com`) once you have a domain.

## 🛠️ Technical Stack
- **Frontend**: HTML5, CSS3 (Custom Properties, CSS Grid, Flexbox), JavaScript (ES6+).
- **Design**: Modern, high-contrast medical aesthetic with responsive layouts for desktop, tablet, and mobile.
- **Assets**: SVG logos, high-quality clinical imagery.

## 📁 Project Structure
- `/css`: Stylesheets including layout and responsive overrides.
- `/js`: Core site logic (navigation, intersection observers for animations, form validation).
- `/assets`: Images and branding assets.
- `index.html`: Single-page application structure.
